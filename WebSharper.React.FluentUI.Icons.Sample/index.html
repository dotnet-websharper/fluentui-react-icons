WebSharper.FluentUI.React.Icons

Fluent UI System icons for WebSharper — rendered from F# through WebSharper.React.

Source

Every tile below is a React component from @fluentui/react-icons, imported through the binding and rendered with WebSharper.React. The page chrome is a WebSharper.UI template; the gallery inside #icons-root is a React tree built from Icons.Helpers. Filter by name, switch the variant, resize the icons or tint them — the controls drive React state.

Usage

open WebSharper.FluentUI.React

// The helpers turn an icon into a React element. Props are string * obj pairs.
Icons.Helpers.addFilled [ "fontSize" => 32; "title" => "Add" ]

// The components themselves are exposed too, for composition in a React tree.
ReactHelpers.Elt Icons.SearchRegular [ "primaryFill" => "#0078d4" ] []
